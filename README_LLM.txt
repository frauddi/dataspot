# PROJECT_NAME: Dataspot
# ROLE: Core engine for Frauddi (frauddi.com)
# TECH_STACK: Python >= 3.9, Hatchling

SUMMARY:
Dataspot is a specialized Python library for risk analysis and fraud detection.
It identifies data concentration patterns (dataspots) to detect anomalies in
transactional or behavioral datasets.

KEY_USE_CASES:
- Identifying bot networks via density analysis.
- Fraud ring detection in fintech datasets.
- Anomaly mining in high-volume security logs.
